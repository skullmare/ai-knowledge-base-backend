## Что это за система

Платформа хранит корпоративные знания в виде **тем** (markdown-документы
с совместным редактированием), нарезает одобренные темы на чанки, кладёт их
векторы в Qdrant и отвечает на вопросы сотрудников в Telegram и MAX,
опираясь только на то, к чему у спрашивающего есть доступ по роли.

Две категории пользователей и они не пересекаются:

* **PlatformUser** — сотрудник, работающий с админ-панелью. Логин, пароль, 2FA,
  права из роли платформы.
* **AgentUser** — пользователь ИИ-агента в мессенджере. Идентифицируется по
  номеру телефона, доступ к темам определяется ролью агента.

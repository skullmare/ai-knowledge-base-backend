# Внешние системы

Все интеграции инкапсулированы в `services/`, клиенты создаются в `config/`.
Ни один контроллер не обращается к внешней системе напрямую — благодаря этому
любую из них можно заменить или замокать одним модулем.

## MongoDB

`config/mongo.js` — подключение, обработка событий `error` и `disconnected`,
корректное закрытие при остановке. Недоступность базы на старте роняет процесс:
приложение без данных бессмысленно.

## Qdrant — векторный поиск

`config/qdrant.js` создаёт клиент **лениво**, при первом обращении. Схема
(http/https) берётся из `QDRANT_URL`, `port: null` не даёт клиенту подставить
`:6333` к managed-адресу без явного порта.

Имя коллекции читается из одного места (`env.qdrantCollection`) и
экспортируется вместе с клиентом. Раньше каждый сервис читал `COLLECTION_NAME`
самостоятельно, и при незаданной переменной синхронизация писала в коллекцию
`undefined`, а поиск шёл в `knowledge_base`.

| Сервис | Что делает |
| --- | --- |
| `qdrant/sync-chunk.js` | удаляет старые чанки темы и загружает новые |
| `qdrant/delete-chunk.js` | удаляет чанки темы по `metadata.topicId` |
| `agent/search.js` | ищет топ-5 с фильтром по роли |

## OpenRouter — LLM и эмбеддинги

`services/openrouter/chat.js` — генерация ответа, `get-embeddings.js` —
векторизация пачкой. Модели задаются переменными окружения
(`OPENROUTER_CHAT_MODEL`, `OPENROUTER_EMBEDDING_MODEL`).

Размерность эмбеддингов должна совпадать с размерностью коллекции Qdrant
(`EMBEDDING_VECTOR_SIZE`, по умолчанию 1536). Смена модели эмбеддингов
требует пересоздания коллекции и переиндексации всех тем.

## Yandex Object Storage (S3)

| Модуль | Назначение |
| --- | --- |
| `yandex/S3/url.js` | сборка публичного URL, генерация ключа, разбор URL обратно в ключ |
| `yandex/S3/upload.js` | загрузка через сервер, гарантированная очистка временного файла |
| `yandex/S3/presigned.js` | ссылка для прямой загрузки браузером (15 минут) |
| `yandex/S3/delete.js`, `delete-list.js` | удаление одного файла и пачки |

Ключ объекта шардируется по первым символам UUID
(`uploads/ab/cd/<uuid>.<ext>`), чтобы в бакете не скапливались десятки тысяч
объектов в одном префиксе. Логика ключа и URL лежит в одном модуле —
раньше разбор URL был скопирован в двух местах и расходился.

Ошибки удаления логируются, но не пробрасываются: неудалённый файл — мусор,
а не причина провалить операцию пользователя.

## SMTP — почта

`services/email/send-email.js` на nodemailer. Используется для кода 2FA,
письма новому сотруднику с учётными данными и ссылки восстановления пароля.
Шаблоны — в `utils/templates/`.

Ошибка отправки обрабатывается по-разному в зависимости от важности:
письмо с кодом 2FA — критично (вход невозможен), приветственное письмо
новому сотруднику — нет, аккаунт всё равно создаётся.

## Telegram

`config/telegram.js` — фабрика бота `node-telegram-bot-api` в режиме polling.
`services/telegram/bot.js` подписывается на `message` и `polling_error`;
ошибка обработчика логируется и не роняет процесс.

## MAX

`config/max.js` — собственный HTTP-клиент поверх `https://botapi.max.ru`:
long polling с маркером, отправка сообщений пользователю и в чат, индикатор
набора. `services/max/bot.js` организует цикл опроса с паузой при пустой
выдаче и уважением `Retry-After` при `429`.

## Hocuspocus — совместное редактирование

`services/collaboration.mjs` — ESM-модуль (зависимости Hocuspocus и BlockNote
поставляются только в этом формате), загружается динамическим `import()`
из CommonJS-обёртки `services/init-collaboration.js`. Подключается к Express
через `express-ws` на `/api/v1/collaboration`.

Если сервер ещё не поднялся, WebSocket-соединение закрывается кодом 1011
с внятной причиной вместо падения.

## Поведение при недоступности

| Система | Что происходит |
| --- | --- |
| MongoDB | процесс не стартует |
| Qdrant | приложение работает; одобрение и удаление тем возвращают ошибку, агент не отвечает |
| OpenRouter | REST API работает; агент возвращает пользователю сообщение об ошибке |
| S3 | загрузка файлов возвращает 500; остальное работает |
| SMTP | вход по 2FA невозможен; создание сотрудника проходит |
| Telegram / MAX | без токена канал просто не запускается |

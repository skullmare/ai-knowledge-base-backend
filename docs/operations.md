# Эксплуатация

## Требования

* Node.js 20 или новее
* MongoDB
* Qdrant
* Бакет Yandex Object Storage
* Ключ OpenRouter
* SMTP-сервер

## Переменные окружения

### Обязательные в продакшене

Их отсутствие роняет процесс на старте (`assertRequiredEnv`).

| Переменная | Назначение |
| --- | --- |
| `MONGODB_URI` | Строка подключения к MongoDB |
| `JWT_ACCESS_SECRET` | Секрет access-токена |
| `JWT_REFRESH_SECRET` | Секрет refresh-токена |

### Приложение

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `NODE_ENV` | `development` | `development` \| `test` \| `production` |
| `PORT` | `3000` | Порт HTTP-сервера |
| `CORS_ORIGINS` | dev: localhost:5173,5174 | Разрешённые origin через запятую |
| `MAIN_DOMAIN` | — | Домен refresh-куки |
| `LOG_LEVEL` | `debug` | Уровень логирования |

### Первичная инициализация

| Переменная | Назначение |
| --- | --- |
| `LOGIN_SUPER_ADMIN` | Логин системного администратора |
| `PASSWORD_SUPER_ADMIN` | Его пароль |
| `EMAIL_SUPER_ADMIN` | Его email (на него приходит код 2FA) |

### Векторный поиск и LLM

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `QDRANT_URL` | — | Адрес Qdrant вместе со схемой |
| `QDRANT_API_KEY` | — | Ключ доступа |
| `COLLECTION_NAME` | `knowledge_base` | Имя коллекции |
| `EMBEDDING_VECTOR_SIZE` | `1536` | Размерность векторов |
| `OPENROUTER_API_KEY` | — | Ключ OpenRouter |
| `OPENROUTER_CHAT_MODEL` | `openai/gpt-4o-mini` | Модель генерации |
| `OPENROUTER_EMBEDDING_MODEL` | `openai/text-embedding-3-small` | Модель эмбеддингов |

### Хранилище файлов

| Переменная | Назначение |
| --- | --- |
| `YANDEX_ACCESS_KEY_ID` | Ключ доступа |
| `YANDEX_SECRET_ACCESS_KEY` | Секретный ключ |
| `BUCKET_NAME` | Имя бакета |

### Почта

| Переменная | Назначение |
| --- | --- |
| `EMAIL_HOST`, `EMAIL_PORT` | SMTP-сервер (порт 465 включает TLS) |
| `EMAIL_USER`, `EMAIL_PASSWORD` | Учётные данные |
| `EMAIL_FROM` | Адрес отправителя |
| `RESET_PASSWORD_URL` | Базовый адрес страницы восстановления на фронтенде |

### Мессенджеры

| Переменная | Назначение |
| --- | --- |
| `TG_BOT_TOKEN` | Токен Telegram-бота; без него канал не запускается |
| `MAX_BOT_TOKEN` | Токен MAX-бота; без него канал не запускается |

## Запуск

```bash
npm install
cp .env.example .env    # заполнить значения
npm run dev             # разработка, nodemon
npm start               # продакшн
```

Docker:

```bash
docker build -t knowledge-base-backend .
docker run --env-file .env -p 3000:3000 knowledge-base-backend
```

## Что происходит при старте

1. Проверка обязательных переменных (в проде).
2. Подключение к MongoDB.
3. Создание или обновление системной роли со всеми правами.
4. Создание системного администратора, если его ещё нет.
5. Снос устаревших индексов `AgentUser` и синхронизация со схемой.
6. Создание коллекции Qdrant и payload-индексов (идемпотентно).
7. Загрузка сервера совместного редактирования.
8. Запуск ботов (при наличии токенов).
9. `app.listen`.

Все шаги идемпотентны — повторный запуск безопасен.

## Остановка

По `SIGTERM` или `SIGINT`: закрытие HTTP-сервера с таймаутом 10 секунд,
затем закрытие соединения с MongoDB. Повторные сигналы игнорируются.

## Мониторинг

* `GET /api/v1/health` — статус, uptime, время сервера.
* `logs/error-%DATE%.log` — серверные ошибки.
* `GET /api/v1/logs?status=error` — ошибки на уровне бизнес-операций.

## Типичные проблемы

| Симптом | Причина |
| --- | --- |
| Агент не находит ничего по существующей теме | тема не одобрена, либо у роли пользователя нет доступа к ней |
| Поиск в Qdrant падает на фильтре | не созданы payload-индексы — перезапустите приложение |
| Все темы «потеряли» индексацию | сменилась модель эмбеддингов; нужна переиндексация с новой коллекцией |
| Не приходит код 2FA | проверьте SMTP и `EMAIL_FROM`; ошибки в `logs/error-*.log` |
| Кука не сохраняется | в проде нужен HTTPS: `secure: true` и `sameSite: none` |
| CORS блокирует фронтенд | добавьте домен в `CORS_ORIGINS` |
